## Mapas clásicos y de The Burning Crusade
![GitHub Latest Release)](https://img.shields.io/github/v/release/Trimitor/WDM-patch?&logo=github)

El parche añade 56 mapas de World of Warcraft, incluyendo mazmorras, continentes y campos de batalla. Todos los mapas son totalmente compatibles con Wrath of the Lich King.

> [!IMPORTANT]
> Este parche es para 3.3.5a, no 3.4.3.

### Instalación
1.  Descargue el archivo apropiado desde [Versiones](https://github.com/Trimitor/WDM-patch/releases/latest) o desde la tabla a continuación, según el idioma de su cliente de juego.
2.  Coloque el archivo descargado en `[Carpeta del juego]\Data\<yourLang>`, reemplazando `<yourLang>` con el código de idioma de su cliente de juego (por ejemplo, `enUS`, `frFR`, `deDE`).

Este parche restaura los mapas clásicos y de The Burning Crusade, haciéndolos disponibles en Wrath of the Lich King.

## Mapas de cavernas y minas
![GitHub Latest Pre-Release)](https://img.shields.io/github/v/release/Trimitor/WDM-patch?include_prereleases&label=pre-release&logo=github) 

Este parche adicional y opcional amplía los mapas disponibles en Wrath of the Lich King. Incluye varias ubicaciones adicionales, como cuevas, minas, entradas a mazmorras, zonas de inicio y áreas ocultas como la Isla GM y Hyjal.

> [!IMPORTANT]
> Este parche es para 3.3.5a, no 3.4.3.

### Requisitos

Para utilizar este parche, **debes** instalar:

- El **parche principal** ([Lanzamientos](https://github.com/Trimitor/WDM-patch/releases/latest))
- El complemento **WDM** y **Astrolabe** ([complementos WDM](https://github.com/Trimitor/WDM-addons/releases/latest))

### Instalación

1. Descargue el parche desde [Lanzamientos](https://github.com/Trimitor/WDM-patch/releases) (marcado como _pre-release_) o desde la tabla a continuación, según el idioma de su cliente de juego.
2. Coloque el archivo descargado en `[Carpeta del juego]\Data\<yourLang>`, reemplazando `<yourLang>` con el código de idioma de su cliente de juego (por ejemplo, `enUS`, `frFR`, `deDE`).
3. Asegúrese de que tanto el **parche principal** como los **complementos** estén instalados y activos.
